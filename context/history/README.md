# History

Planning and progress docs from the original build of this site, kept because they
record why things were done, not because they describe the tree today. They have
already drifted: they name eight themes (there are far more, from
zwipe-components), Iosevka (the site uses JetBrains Mono), a `ProjectType` enum that
no longer exists, dioxus 0.7.1, and a Capture project that is not on the site.

Read them as a record of intent. `../overview.md` is the current map.
